# CtrlTab Panel — Arc Style

Мод для Zen: скруглённая панель, превью со спокойными тенями,
маленькие favicon рядом с названием и лавандовое выделение выбранной вкладки.
Цвета адаптируются к светлой и тёмной теме браузера. Учитываются уменьшение
анимаций и системный режим высокой контрастности.

Это самостоятельная реализация, вдохновлённая идеей
[Better CtrlTab Panel](https://github.com/psu/zen-mods/tree/main/better-ctrl-tab)
и визуальным стилем Arc.

## Установка через Sine

1. Отключите Better CtrlTab Panel и другие моды, меняющие эту же панель.
2. Откройте настройки Zen → Sine Mods и вставьте ссылку в поле установки
   из GitHub:

   ```text
   https://github.com/b2theh/CtrlTabPanel
   ```

3. В настройках Sine включите установку JavaScript из неофициальных источников
   (Enable installing JS from unofficial sources), установите мод и перезапустите Zen.
4. В настройках Zen → Основные → Вкладки включите переключение Ctrl+Tab
   в порядке недавнего использования. Альтернатива: в `about:config`
   установите `browser.ctrlTab.sortByRecentlyUsed` в `true`.

Версия 1.1.0 добавляет небольшой локальный скрипт для изменения размера
с сохранением положения панели по центру экрана. Если ранее был добавлен ручной импорт этого мода в
`userChrome.css`, удалите его перед установкой через Sine.

## Размер панели

Откройте **Sine Mods → CtrlTab Panel — Arc Style → настройки** и выберите
**Panel size / Размер панели**: 65%, 80%, 100%, 115% или 130%.
100% сохраняет исходный размер. Настройка применяется при следующем открытии
Ctrl+Tab; после первого обновления до 1.1.0 нужен перезапуск Zen для загрузки скрипта.

Меняется ширина панели и размер превью; текст и иконки остаются читаемыми.
Максимальная ширина ограничена самим Zen по размеру экрана, поэтому на небольшом
экране крупные варианты могут выглядеть одинаково. Для нескольких рядов также
нужно учитывать высоту экрана.

## Установка через userChrome.css

1. Отключите Better CtrlTab Panel и другие моды, меняющие эту же панель.
2. В настройках Zen → Основные → Вкладки включите переключение Ctrl+Tab
   в порядке недавнего использования. Альтернатива: в `about:config`
   установите `browser.ctrlTab.sortByRecentlyUsed` в `true`.
3. В `about:config` установите
   `toolkit.legacyUserProfileCustomizations.stylesheets` в `true`.
4. В `about:support` откройте папку профиля. Создайте в ней папку `chrome`,
   если её ещё нет, и скопируйте туда папку этого мода под именем `CtrlTabPanel`.
5. В начало файла `chrome/userChrome.css` добавьте строку (если файла нет,
   создайте его):

   ```css
   @import url("CtrlTabPanel/chrome.css");
   ```

   Все `@import` должны находиться перед обычными CSS-правилами.
6. Полностью перезапустите Zen.

Для удаления уберите строку импорта и перезапустите браузер.
Ручной импорт подключает только оформление. Настройка размера доступна
при установке полного мода через Sine.

## Настройка

Переменные находятся в начале `chrome.css`:

| Переменная | Значение | Назначение |
| --- | --- | --- |
| `--arc-ct-radius` | `22px` | Скругление панели |
| `--arc-ct-card-radius` | `14px` | Скругление карточек |
| `--arc-ct-padding` | `16px` | Отступ внутри панели |
| `--arc-ct-gap` | `8px` | Расстояние между карточками |
| `--arc-ct-accent` | `light-dark(#6b50b6, #c6b2ff)` | Контур выбора |
| `--arc-ct-selected` | `light-dark(#e8e1f2, #42394f)` | Фон выбора |

## Проверка в Zen

Разметка и имена переменных сверены с установленным Zen **1.24b**.
Панель не запускалась; визуальная и интерактивная проверка остаётся пользователю.

Автоматические проверки: `node --check size.uc.js` и
`node --test tests/size.test.cjs`. Проверяются размеры, центрирование по формуле
Zen, неверные значения настройки, восстановление после ошибки и отключение скрипта.

- Откройте минимум три обычные загруженные вкладки. Зажмите Ctrl и нажмите
  Tab, удерживая Ctrl чуть дольше 200 мс: это штатная задержка Zen.
- Нажимайте Tab для выбора и отпустите Ctrl для перехода. При двух вкладках
  Zen переключает их напрямую, без панели.
- Проверьте длинные названия, вкладку без favicon, светлую и тёмную тему,
  кнопку списка всех вкладок и небольшой экран.
- Если используется `browser.ctrlTab.maxPreviews` больше 7, проверьте
  несколько рядов. Их количество и число столбцов задаёт сам Zen.

Порядок вкладок, сочетания клавиш и создание превью управляются Zen.
Скрипт размера масштабирует исходные размеры только на время штатного расчёта
положения панели и затем восстанавливает их. При отключении мода в Sine
исходный обработчик восстанавливается.
